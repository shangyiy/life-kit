# /optionality

**Core principle:** Prefer decisions that leave credible next moves when their
value exceeds the cost, but spend options deliberately when commitment creates
more value than continued flexibility.

Boundary: `perspective` prevents fixation on one proposed solution;
`optionality` prevents dependence on the only feasible course.

## Workflow

1. **Map the next choices.** For each present decision, name the alternatives
   it preserves, creates, weakens, or closes, including the next-best use of
   the same time and resources. State the credible alternative and threshold
   for walking away from the present course.
2. **Test each claimed way out.** Record who or what holds it and whether the
   commitment is written or otherwise verifiable; its stated terms; whether
   it survives the same event as the risk; and whether it lasts through the
   entire risk window.
3. **Size the coverage.** Count a credible way out only for the exposure it
   actually covers. Treat every gap, and the whole exposure when a way out is
   not real, as if no fallback existed.
4. **Price use and delay.** Include the direct cost of exercising an option,
   the opportunities it gives up, and value lost while waiting. Note the last
   useful decision point rather than assuming flexibility lasts forever.
5. **Judge the environment.** Prefer settings with a high density of reachable
   people, information, resources, and paths, not merely many nominal choices.
6. **Choose when to commit.** Keep options while learning or downside warrants
   it; commit when concentration, trust, compounding, or timing is worth more.

## Checklist

- Alternatives are feasible, distinct, and available to the decision-maker.
- Every way out has a holder, evidence, terms, duration, and failure check.
- Coverage matches the full exposure or the uncovered part is explicit.
- Exercise cost, opportunity cost, decay, and timing are included.
- The decision explains why flexibility or commitment is more valuable now.

## Anti-patterns

- Counting an unwritten assurance as a guaranteed fallback.
- Treating several names for the same fragile path as diversification.
- Ignoring a gap because some part of the exposure is covered.
- Waiting by default while an option or opportunity loses value.
- Keeping every option open so long that none receives meaningful commitment.

## Output

Return the decision; credible alternatives; options created and closed; each
way out's holder, evidence, terms, duration, correlated failure, coverage, and
cost; timing and decay; environment assessment; and commitment rationale.
