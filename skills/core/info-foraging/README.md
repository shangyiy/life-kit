# info-foraging

Principles for searching for information under limited attention
(`/info-foraging`). Information foraging theory treats looking for
information like animals looking for food: follow cues to promising patches,
and leave a patch when it pays less than the others.

## Credit

- Peter Pirolli and Stuart Card, "Information foraging", *Psychological
  Review* 106(4), 643-675, 1999
- Eric L. Charnov, "Optimal foraging, the marginal value theorem",
  *Theoretical Population Biology* 9(2), 129-136, 1976
