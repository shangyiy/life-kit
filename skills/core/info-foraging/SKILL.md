# Info foraging

Get the most value for the attention spent looking. These rules hold for any search, in any field. What counts as valuable comes from whoever runs the search.

## Rules
- **Popularity is a hint, not value.** Many reposts, votes or citations tell you where to look, not that it is good. Open the thing itself before judging it.
- **Search quiet places on purpose.** Good quiet work gives off little hint, so a search ranked by popularity never finds it. Spend part of every search where attention is low: small projects, practitioner forums, other languages, other fields.
- **Raise the bar when good items are plentiful.** When many items qualify, keep only the best. When few do, report fewer. Never pad.
- **Leave a source when it stops paying.** Stop digging a source once it stops turning up candidates. Count how many kept items each source produced; drop a source that keeps producing nothing, and try a new one when all are thin.
- **Credit the source where you first found an item**, so the counts stay honest.

## Example
A search for good new testing methods: the most-discussed thread on a big forum points to a well-known method, so open it and judge it yourself. Then spend part of the search in a small practitioners' forum and in little-known write-ups, where a sound method with no attention may sit. If the small forum gives nothing two searches in a row, replace it.

## Why
Information foraging theory (Pirolli & Card, 1999) treats looking for information like animals looking for food: follow cues to promising patches, leave a patch when its yield drops below what else is available, and be pickier when food is plentiful.
