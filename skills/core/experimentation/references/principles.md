# Experimentation principles

1. **Separate assumptions from evidence.** Confidence, plausibility, and
   agreement are not observations. Write down what must be true and what is
   already known before choosing a test.
2. **Experiment only where action can teach.** More thought is useful while
   the answer follows from available facts. Experiment when reality must
   answer and the answer can change a decision.
3. **Prefer reversible learning.** Under uncertainty, preserve the ability to
   stop, undo, or change direction. Increase commitment only as evidence earns
   it.
4. **Risk only an affordable downside.** Size the test by what can be lost,
   not by the hoped-for upside. A small test is not ethical or useful if its
   burden falls on someone who did not accept it.
5. **Failure is information only when interpretable.** A failed test teaches
   when its assumption, conditions, and evidence rule make the result legible.
   Preventable failure and uncontrolled harm are not learning strategies.
6. **Learning must alter action.** Record surprises, update the assumption,
   and make the next decision. Repeating a test without an update is motion,
   not experimentation.
