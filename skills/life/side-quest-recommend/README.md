# side-quest-recommend

Gives a short menu of real, doable things to do near you, led by one recommendation, from a tiny at-home start to a local outing or a simple getaway (`/side-quest-recommend`). Every outing rests on a page that was opened for the date and place.

- `SKILL.md`: grounding rules, the context packet, which modes run, the ranking, and how the menu is shown.
- `modes/`: one file per mode (starter, half-day, weekend).
- `references/web-search.md`: the lookup pipeline and regional notes.
- `references/ab-variant.md`: an optional variant that runs each mode twice.
