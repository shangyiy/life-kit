# way-outs

The investing use case for risks that lean on a fallback (`/way-outs`).
`SKILL.md` holds the two checks and defers every other principle to
[`investing`](../../core/investing/SKILL.md).

These ideas are the author's own reading:

- A way out is real only if it has a named holder, stated terms, lasts through
  the whole time the risk could hit, and does not fail in the same event.
- A passing way out is real; its cost and gaps are named, not held against it.
- A missing fact is asked for once; if it stays missing, that test fails.
- Count only passing fallbacks, each up to the part of the risk it covers.
- An option can lose value while you wait; there is no hurry only while its
  last date lies beyond the time you need to decide.
- If no fallback passes, decide as if there were no way out.
- Decay never replaces the check that the way out is real.

There is no literature source. These principles are not affiliated with or
endorsed by anyone.
