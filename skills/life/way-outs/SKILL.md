# /way-outs

The use case for taking a risk because you could fall back. Every principle of
[`investing`](../../core/investing/SKILL.md) applies unchanged; this skill adds
two checks, the first with a counting rule. Use it to make the decision or to
review one; in a review, name each breach once, with its fix.

## Checks

1. **Is the way out real?** A fallback is the path you name to catch you if
   the risk hits. Test it four ways:
   - Named holder: you can say who or what catches you.
   - Stated terms: you can say under what conditions it does.
   - Lasts: it lasts through the whole time the risk could hit; one that ends
     partway through fails. An unknown end, of the fallback or of the risk's
     window, is a missing fact.
   - There when needed: it does not fail in the same event as the risk.

   If a fact a test needs is missing, ask once, listing every missing fact. A
   fact that stays missing, or that you cannot ask for, fails that test. Take
   facts the person deciding reports as already verified as given, and do not
   re-check them unless they conflict with other evidence. Weigh every other
   claim, including one from anyone who gains from your choice, as `investing`
   3 and 4 say.

   Verdict: a fallback that fails any test is a claim, not a way out. One that
   passes all four is real, and that verdict does not wait on more checks.

   Next: name what using it costs and what it leaves uncovered, without
   lowering the verdict. To size the decision, count only the fallbacks that
   pass, each only up to the part of the risk it covers, and decide the rest
   (all of it if none passes) as if there were no way out (`investing` 1).
2. **Is the option decaying?** An option is a choice you hold now: a way out
   that passed check 1, or the chance it backs, even if no fallback passed.
   Ask whether its value shrinks the longer you wait, what it would be worth
   if used later, and the last date it can be used. For a way out that date is
   the Lasts date, not a second test. If it shrinks, waiting has a cost
   (`investing` 5). If it holds, there is no hurry exactly while that date lies
   beyond the time you need to decide. Decay is a reason to decide, and
   deciding includes declining. It never replaces check 1.
