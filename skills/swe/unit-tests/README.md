# unit-tests

Agent skill for writing and reviewing unit tests (`/unit-tests` and children:
`/black-box`, `/test-oracle`, `/white-box`, `/mutation-testing`).

## Credit

Principles and workflow are adapted from Carnegie Mellon University courses
taught by **Prof. Hakan Erdogmus**:

- **Foundations of Software Engineering (FSE)** — CMU 18-652  
- **Software Verification and Testing (SVT)** — CMU 18-654  

This skill pack is an independent restatement for agent use. It is not
affiliated with or endorsed by CMU or the instructor.
