# inspiring-idea

Given an idea and a reader's context, say whether the idea can inspire the
reader's own work, why, and how to apply it (`/inspiring-idea`). An idea
inspires when it is good and shares the relations of a problem the reader
has, not its surface; the reader rarely sees such a match alone, so it is
pointed out, and other fields are a fruitful source.

## Credit

- Dedre Gentner, "Structure-mapping: A theoretical framework for analogy",
  *Cognitive Science* 7(2), 155-170, 1983
- Mary L. Gick and Keith J. Holyoak, "Analogical problem solving", *Cognitive
  Psychology* 12(3), 306-355, 1980
- Paul Graham, "How to Get Startup Ideas", November 2012,
  paulgraham.com/startupideas.html ("The clash of domains is a particularly
  fruitful source of ideas.")
