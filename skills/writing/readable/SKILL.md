---
name: readable
description: >
  Default prose style for user-facing text: one simple idea, then
  elaboration, then an example when it helps. Use for every writeup,
  explanation, README, or reply the reader will see, and when the
  user runs /readable.
license: MIT
---

Write so a reader with no time can follow on the first pass.

For each point:

1. **Idea** — one sentence as subject + verb + object. A reader with no time can infer the elaboration from this sentence alone. Rewrite the idea until they can.
2. **Elaboration** — a few sentences that explain the idea in plain words.
3. **Example** — add one concrete case when it makes the idea easier to see.

Use short, common words. Give each word one meaning.

Use a hard word only after this writeup already defined it. After that, reuse is fine.

Keep the author's argument when the source already has one. Change only the words and the shape of each point.
