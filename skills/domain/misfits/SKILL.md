# /misfits

The domain of learning from a record of work. A misfit is a stress between the
work and its context. A pattern names a context, its forces (needs and
pressures) and a configuration that resolves them. An observer finds misfits;
an independent judge tests patterns. Use these to do the work or to review it;
in a review, name each breach once, with its fix.

## Principles

1. **Start from misfits, judged by consequences.** Good fit shows only as the
   absence of misfits, which are specific enough to name. Read how the context
   responded to the work, not your own reaction.
2. **Read the signs in the record.** Failure followed directly by correction;
   a misfit returning worse; something made but unused, or things piling up; a
   fix that hurts a neighboring part; gaps between parts left untended; one
   need served at another's expense; a name with nothing behind it. Work
   repeated unchanged is fair evidence of fit.
3. **Write each misfit as a binary variable** two readers would judge alike,
   of equal scope, as independent as is reasonable, and as small as possible.
   Include needs met today that no one feels: even small forces left out
   always work to make the system fail. The list stays a temporary catalogue.
4. **Group misfits by links, not by likeness.** Two misfits are linked when
   acting on one necessarily makes the other harder or easier; write down why,
   since past co-occurrence is no reason. Keep groups dense inside, sparse
   between. Familiar categories control what you see: headings only list.
5. **Find the invariant, named so you can tell at once if it is present.**
   Split records of one context into good and bad; find a relation all the
   good have and all the bad lack. Write it as context, forces and one
   configuration, precise enough to be challenged, and keep its spirit, not
   just its letter; a weak name means an unclear concept.
6. **A pattern lives only if it resolves all the forces present,** judging
   none illegitimate. A real problem and a configuration that solves it can
   each hold while the whole is dead. Judge each force per case: resolved,
   unresolved or worse. Forces are never known exactly, so ask what tension
   remains and what new forces it creates, and list those as misfits.
7. **Test by paired comparison.** Pair records of one context and similar
   scope, with and without the configuration. The judge, blind to which is
   which, asks which leaves less tension, never which is liked, going A, B, A.
   If the case without it is better, or honestly no different, the pattern is
   no good. Only converging independent verdicts count.
8. **Retest on any sign of a dead pattern:** the name without the spirit;
   halfhearted use; use because it is at hand; made to project an image;
   makers who never face its results; no staying power. A case without the
   pattern can still live.
9. **Hold each pattern as a guess, and evolve the set one pattern at a time.**
   Revise or reject one on a case it cannot explain; expect to discard most.
   Change only on misfit, and return patterns to the work they came from. New
   configurations create new forces, so the set is never finished.
