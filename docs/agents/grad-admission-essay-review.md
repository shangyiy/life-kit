# grad-admission-essay-review

Reviews one graduate admissions essay for one target program by combining
`info-foraging`, `perspective`, `needs-to-signals`, `find-the-argument`,
`purpose` and `readable`. The agent itself is
[`agents/grad-admission-essay-review.md`](../../agents/grad-admission-essay-review.md).
